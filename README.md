# CCDC-UWStout

UW-Stout CCDC team repository.

Created by Matthew Pomes. Maintained by the UW-Stout CCDC team.

Most files are stored in our Google Folder. This repo is only used for storing scripts
and files for easy download from VMs, via `curl` or similar untility.

## Directory structure

- `firewall`: Scripts & Files for Firewalls AND for VyOS
- `linux`: Scripts & Files for Linux Boxes
- `windows`: Scripts & Files for Windows Boxes
- `templates`: Word templates for injects and incident response. Includes Legal Banner Template

## Curl

Using curl, or a similar utility, files can be downloaded onto any machine.

`wget https://raw.githubusercontent.com/UWStout-CCDC/CCDC-scripts/master/<file>`
